# Vento Lab · 实验日志对比

用浏览器打开两次实验的 CSV，按列名选择同一个物理量，检查采样质量，并导出可离线打开的 HTML 报告。列顺序可以不同，增加无关列也无需改宏。文件在本机处理。

[在线打开 Vento Lab](https://lazyerzzz.github.io/vento-lab/) · [下载离线版 ZIP](https://github.com/lazyerZZZ/vento-lab/archive/refs/heads/main.zip)

## 开始使用

1. 在 GitHub 选择 **Code → Download ZIP**，解压整个目录，用浏览器打开其中的 **index.html**。无需安装依赖。
2. 点击 **载入合成示例** 可先看到两条阶跃响应。使用自己的数据时，选择实验 A 的 CSV，可选填实验 B。
3. 为每个文件确认时间列、时间单位、实测列。跟踪实验可另选目标列。填写信号单位，点击 **生成分析**。
4. 填写复核说明后点击 **导出离线 HTML 报告**。报告可独立打开，包含文件名、列映射、采样质量、曲线和备注。

## CSV 格式

UTF-8 编码、逗号分隔，首行为不重复的列名。每份上限 10 MiB，至少三行有效样本。时间列使用数值秒、毫秒或微秒。下面是没有目标列的温度实验：

```csv
time_s,temperature_C
0,21.1
1,21.4
2,21.6
```

对于设定值跟踪实验，可使用 `time_s,target_rad,actual_rad` 等表头。两份文件分别映射，两个实验的信号单位应一致。

## 计算口径

- 有效行必须包含有限的时间、实测值，以及已选目标列的数值。质量统计包含无效行、重复时间戳、原始顺序中的逆序跳变，以及超过正时间间隔中位数三倍的间隔。保留重复样本。
- 每条曲线以该文件最早有效时间为零点；两个文件之间不插值。图形最多约 1,500 个显示点／文件，短时尖峰可能在显示时略过。
- 指定目标列后，为每次实验分别计算实测减目标的 RMSE、MAE、绝对误差 P95、最大绝对误差，以及最后 10% 有效样本的平均有符号误差。P95 使用线性插值，指标使用全部有效样本并按样本等权。
- 浏览器刷新会清空工作区。报告包含导入时使用的文件名、备注和可视化数据，分享前可先打开检查。

## 运行测试

安装 Node.js 18 或更高版本后，在仓库根目录运行：

```sh
node tests/core.test.js
```
